# La Calculatrice

A minimal financial calculator web app for comparing loan scenarios and retirement savings projections. Built with Next.js.

[Try it out](https://la-calculatrice-gold.vercel.app/)

## Features

- Loan Calculator
- RRSP/Investment Calculator

## Make it your own

1. Fork and clone this repo
2. Deploy it to Vercel
3. Calculate!
